# Turno de caos · GitHub Pages

Versión web del prototipo, compilada desde SamNavCan/tbdndg.

En Settings → Pages, selecciona **Deploy from a branch**, rama **gh-pages**, carpeta **/ (root)** y guarda.

Dirección prevista: https://samnavcan.github.io/tbdndg/

En iPhone: abre con Safari en horizontal. Opcional: Compartir → Añadir a pantalla de inicio.

El progreso se guarda en cada navegador; no se transfiere desde el archivo descargable ni entre dispositivos.
